telelink > commands



  watcher         start watcher in new window

  watcher stop    force stop watcher window

  intake          LAN share — QR or text the link

  intake global   public URL (internet, not just LAN)

  intake stop     stop intake server

  outtake <url|file…>  QR — link or GitHub share (multiple files → zip)

  caught          browse caught notifications (table, json, gron)

  contacts        contacts table (name → phone, match rules)

  send <who> msg  text contact or +number (opens Phone Link)

  calendar        scheduled SMS events table

  calendar add <name> <who> <when> <msg>   schedule a message

  calendar status calendar + Google sync health

  calls           recent Phone Link calls (default 1d retention)

  missed          missed calls table

  help calls      call log, watcher requirement, reminders

  help sync       Phone Link re-sync, stale cache, auto-sync config

  sync            re-sync Phone Link + contacts (auto every 30m)

  config          show config, paths, and contacts

  config reset    restore config.yaml from config.example.yaml

  agent           AI cheat sheet (same as AGENTS.md)

  agent context   JSON for Cursor/Claude — tone, caught, commands

  ars start <session> <contact>   auto-reply session (new window)

  ars next <session> [--raw]      what to do now (agent driver)

  ars status [<session>] [--raw]  session state

  ars stop [<session>]            stop session(s)

  ars list [--raw]                list sessions

  ars ack <session> [--force]     agent turn complete

  ars pause <session>             pause poll loop

  ars resume <session>            resume poll loop

  ars wait <session> [--raw]      block until reply needed

  how             full how-to guide (read this first)

  how <topic>     topic guide (e.g. how watcher, how intake)

  help analyze    AI snapshot folder (.analyze)

  help wipe           clear caught, contacts, db, attachments, …

  help config reset   restore config.yaml from example

  status          quick summary

  wipe <target>   clear local data (caught, calls, sent, contacts, all, …)

  wipe all --yes  reset all data/ files (keeps config.yaml)

  clear / cc        clear screen

  help            this screen

  exit            quit

tips



  owner: in config.yaml is you (your business / short name) — not a contact.

  contacts: edit data/contacts.jsonl — match rules tag notifications.

  intake: phone must be on the same Wi-Fi as this PC.

  analyze: data/.analyze/latest.png — AI snapshot of last attachment (help analyze).

  analyze off: config edit analyze_screenshot false

  calls: watcher must be open when Phone Link shows call toasts; data/calls.jsonl (not caught).

  sync: re-reads Phone Link contacts.db; auto every 30m (config edit auto_sync false to disable).

  calls ttl: config edit calls_ttl 2d  ·  reminders every 10m (calls.remind_interval)
